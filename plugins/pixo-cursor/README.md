# Pixo for Cursor

Generate images, videos, speech, and music from Cursor with your Pixo account.
The plugin connects Cursor to Pixo's hosted MCP server and includes a skill
for choosing models, estimating costs, and retrieving finished results.

## Connect Pixo

Add the Pixo plugin in Cursor, then open **Cursor Settings → Tools & MCP**
and connect the Pixo server. Sign in to Pixo in your browser and approve the
connection. Pixo uses OAuth, so you do not need to paste an API key.

You can also add `https://api.pixo.video/mcp/models/` as a remote MCP server
through Cursor's MCP settings.

## Try it

Ask Cursor to list Pixo video models without generating anything to verify
the connection. Then describe the image, video, voiceover, or music you want.
Generation uses credits from the connected Pixo account. Ask for a credit
estimate before generating if you want to check the cost first.
